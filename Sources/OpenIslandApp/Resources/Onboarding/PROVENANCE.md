# Native welcome media

Approved visual and cue source: `review/v0.1.1-intro-r6`, commit
`32c94f2fb0282242d17ef4db63f6c169a874e25f`.

The native CGContext renderer ports `prototypes/v0.1.1-review/intro-scene.js`
and its final title timing from `review.js` / `review.css`. PNG atlases,
stills and four task rows are unchanged copies from that approved prototype.
`native-media.json` retains their exact native recording ranges, frame counts,
source crops and demo provenance. Those task recordings contain example
sessions, not live tasks or successful integration evidence. See the full
capture/source records in `prototypes/v0.1.1-review/assets/SOURCES.md`.

Official brand marks remain their owners' marks. Seven PNG marks are copied
unchanged. Grok and DeepSeek SVG marks were rasterized using macOS `sips` for
native image decoding; their paths were not redesigned. Brand animation does
not assert that every displayed tool supports identical runtime capabilities.

`intro-v6.wav`: 22 seconds, 48,000 Hz, stereo signed PCM16. Generated by the
integration agent from the approved `intro-audio.js` cue sheet and the same
Web Audio tone/air/swell primitives, master gain 0.7, and compressor settings
in `review.js`, using OfflineAudioContext. Only PCM quantization changes the
rendered score. Peak 0.3967042565, RMS 0.01582468177; no clipping. The native
AVAudioPlayer device clock drives sprites and scene motion from the same
scheduled origin, including mute/unmute without restarting the score.
