# AIsland v0.1.1 引导下一轮音画优化计划

日期：2026-10-03。状态：`NOT_STARTED_WAITING_CURRENT_EFFECT_CONFIRMATION`。

用户要求把音效递进、多样性和视觉表达放到下一轮：先完成此前反馈并让用户确认，之后再优化这两部分。本记录只更新计划，不修改第五版画面、声音或正式应用，也不把此次反馈视为第五版已通过。

## 启动条件与顺序

1. 用户先确认[第五版](aisland-v0.1.1-intro-revision-5.md)的四 Agent 任务汇入、汇聚与归位声音、原生角色和数量格、转场及中英文版本。如仍有问题，先完成该范围的修正。
2. 确认后开始本轮音画设计：先形成画面与声音共同时间轴，拿出可播放样段，再完成整段迭代。
3. 新版完整音画再次交给用户确认，之后继续正式原生引导实现。接入和自定义任务声音仍走各自的真实效果验收。

## 音效：随画面推进形成强弱和长短变化

- 根据画面位移、聚合过程、状态变化与落位，设计蓄势、递进、落点和余韵；强度、音色层次及空间变化一起形成节奏。
- 需要持续过程的段落可用约 3–4 秒的声音，单次操作继续用合适的短提示。时长由画面与用户体感决定，不要求所有音效变长，也不默认延长整个开场。
- 在已选 A 方向下丰富音色、质感和表现方式，控制相似提示的重复。连续声音与审批、回答、完成提示之间留出听觉空间，避免尾音挤压下一段的信息。
- 开场、Logo 汇聚、任务汇入和归位共同编排整体起伏与安静间隔。已明确删除的展开尾声和重复收尾动机保持删除，除非用户另行改变意见。

交付包含每段的声画起点、递进区间、落点、尾音和静默区，以及可实际播放的整段音画。用户试听判断完整节奏、强弱舒适度、丰富度和提示区分；模型与波形分析不能替代听感确认。

## 画面：用视觉语言解释产品

- 重新观察 Dia 及相关案例怎样通过连续变形、空间关系、交互和信息显隐让用户理解，记录可用于 AIsland 的表达方式；不套用每个阶段都配固定角落介绍文字的结构。
- 用 Agent 与任务的聚合关系、权限请求出现并得到回应、回答后任务继续、最后归位等可见变化表达用途。沿用真实原生演示内容和来源边界，任务逻辑与独立 Logo 汇聚保持清楚。
- 文字只在建立品牌、关键概念或需要真实操作时出现；根据画面焦点调整位置、长度与停留时间。允许部分段落只靠画面呈现，不强制逐段标题和说明。
- 同步设计中英文文案与画面布局，保留跳过、静音、减少动态效果和后续配置入口的可理解性。

交付包括新的视觉分镜、文字出现策略及可播放样段。审阅时核对：弱化文字后能否理解任务来自不同 Agent、何时需要用户回应、回应后发生什么，以及小岛最终如何进入日常使用。

## 完成与停止节点

保留第五版供前一阶段确认；下一轮以独立修订号交付。检查完整播放、声画同步、中断取消、两种语言布局和转场性能后，停下来让用户评价实际体感。编译或播放成功不等于效果通过。用户确认前不进入正式原生引导移植，也不影响 v0.1.0 公证发布线。
