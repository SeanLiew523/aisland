日期：2026-10-03。状态：`REVISION_REQUESTED`。第二版尚未通过效果验收。用户要求缩小和分开外围模块、删除展开末尾约第 4 秒音效、收紧转场与减少重复声音、最终对齐真实 MacBook 刘海。随后明确：任务阶段复用 AIsland 站点原生演示素材；另设 Agent Logo 汇聚模块，不能把自制任务卡加标识当成这项要求。

- 去掉第二版自制文档、代码、审核卡片。汇入只取站点原生列表里实际可见的 Codex / Claude 两条会话行，缩小后置于刘海两侧，保留中间空隙；没有补造列表中未显示的第三条。
- 审批、回答、会话与完成直接使用站点原生视频像素。保留原来的 Agent 标记、任务名、权限请求、问题、选项及按钮；只处理素材裁切、壁纸遮罩、摆放与转场。沿用站点的“原生录制 / 示例会话”边界，未发送真实审批或跳转。
- 先单独展示 Claude、ChatGPT、Gemini、Grok、Kimi、MiniMax、ZCode、DeepSeek、WorkBuddy 九个官方标识，再轻巧跳入岛。该段不带任务字段，也不把标识当作对应工具已经完成接入验收的声明。
- 保留 A 的开场蓄势和一次共鸣。删除旧版展开末尾空气扫声、汇入和返回确认声、收尾再次播放的品牌动机。三个状态只在各自落点提示一次，审批改为单次短提示，回答用不同的开放音色。完整听感仍需用户确认。
- 全程从 28 秒收紧到 22 秒。录像取样保持原来的时间，不加速原生动画。减少动态效果改用原生静帧，取消 Logo 位移与原型转场。

## 验证与确认

第三版曾完成浏览器完整播放、窄屏布局和素材显示检查；用户实际反馈暴露声音缺失和转场重影。第三版原生壳编译和只读几何通过，但首次启动在内容规则编译处退出，未取得原生显示证据；第四版修复并重新验证。模型不能替代用户试听；素材可播放、编译通过和几何核对均不等于效果通过。

用户继续要求：Logo 汇聚和任务汇入要有独立声音；汇入不能只露出 Claude / Codex 两条；两个转场有重影卡顿；归位应采用原生左角色、右智能体数量格。后续结果见[第四版记录](aisland-v0.1.1-intro-revision-4.md)。

本轮仍停在用户效果确认点。用户审阅第三版的任务素材呈现、Logo 汇聚、整体节奏和真实屏幕归位后，才继续原生安装引导功能开发。Hermes CLI / DeepSeek Harness 与自定义声音的真实应用验收仍独立待办。本轮不操作 v0.1.0 公证发布。
