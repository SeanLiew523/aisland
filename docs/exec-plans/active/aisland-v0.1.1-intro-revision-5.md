# AIsland v0.1.1 安装引导第五版

日期：2026-10-03。状态：`READY_FOR_EFFECT_REVIEW`。第四版仍收到汇入只显示两个 Agent、归位缺少声音的反馈；用户同时提出首次打开按系统语言自动显示中英文引导。本版完成具体可审阅结果，停在用户要求的效果确认节点，尚未实现正式应用的安装引导。

## 本版结果

- 汇入增加为 Claude、Codex、Gemini、WorkBuddy 四个模块。直接从当前应用的 `IslandSessionRow` 原生组件离屏导出中英文示例，保留任务形式、品牌徽章和排版；360×93 pt、2× PNG 缩小后呈现，四个模块分别置于岛的左右两侧，留出空隙。
- 九个 Logo 仍是独立模块，连续汇合声配合收束。任务模块落位和汇入各有短提示；归位在 20.7 秒实际贴合屏幕顶部时增加一次短促贴合声。已删除的展开尾声与重复收尾动机不会恢复。声音是原创合成草样，完整听感待用户试听。
- 审批、回答、会话、完成和收起态直接使用已保存的中英文站点原生录像。跳过源录像展开时的半透明重叠帧，使用单个不透明面板揭示；动画保留源 30 fps 和原速。播放前解码并裁切小帧纹理，避免转场时上传大图集。
- 归位保留原录像左侧圆角色、右侧三色智能体数量格；本机原生全屏末态为 x=725、y=0、277×32 pt，中部覆盖硬件缺口，角色和数量格位于两侧可见区域。
- 引导文字、控件、设置示意和任务素材都具备中英文版本。浏览器首次依据浏览器语言，独立原生审阅壳依据 `Locale.preferredLanguages.first` 自动选择；右上角允许临时切换。审阅器不读写生产语言偏好。正式原生实现将沿用已有 `LanguageManager`：初次 `.system`，用户手动语言优先，并保留现有繁体中文契约。

原站点录像只有 Claude / Codex 两条可见任务行；补充四条行是新的原生组件示例捕获，不能称为已发布录像或真实任务结果。两种语言的导出均不创建窗口、AppModel、bridge、真实会话或交互回调；临时捕获源将语言偏好 IO 替换为显式 locale。生产源文件 SHA256、PNG 校验值与 provenance 已核对一致，来源见[素材说明](../../../prototypes/v0.1.1-review/assets/SOURCES.md)。

## 已完成验证

- JavaScript 语法、Git 差异和文档检查通过；原生审阅壳构建、Info.plist 与签名检查通过。
- 浏览器中英文各完整播放 22 秒，无控制台 warning/error。英文观测 2650 个帧间隔，最大 21.4 ms，两个转场窗口最大 9.4 ms；中文观测 2652 个间隔，最大 10.5 ms，转场最大 10.5 ms。两次均未观察到超过 50 ms 的间隔。这是本机观测，不代表所有硬件表现或用户效果认可。
- 英文 1280×850 及 426×900 布局检查通过，窄屏没有横向溢出；中文汇入静帧已检查四个 Agent 模块。中文系统浏览器默认选择中文，手动英文完整播放后可恢复跟随系统。
- 本机原生审阅器实际从头播放到设置页，取得归位截图 `output/verification/v0.1.1-intro-revision-5/native-docked.png`。加载回执 `native-layout.json` 中窗口、视口与画布均为 1728×1117、原点 (0,0)。点击“退出审阅”后进程已退出，桌面恢复。
- 未读取或改写生产设置、用户会话及第三方配置；没有产生触控板触感。正式首启、升级、重播、外接屏、屏幕变化及触感仍属于后续原生验收。

等待用户确认四模块汇入、归位音效、中英文介绍及整体转场效果。用户随后要求把音效递进与多样性、减少逐阶段文案并增强视觉表达留到下一轮，见[下一轮计划](aisland-v0.1.1-intro-next-iteration.md)：先确认此前反馈，再迭代这两部分，迭代效果再次确认后继续正式原生引导。此次反馈不是第五版通过记录。Hermes / DeepSeek 真实接入与三类 MP3 真实事件效果仍独立待验收；v0.1.0 公证发布继续由原窗口负责。
