## 用户修订与实现

已读取用户提供的七张截图。最后追加的红框说明优先：只在现有岛左侧留白加入真实 SVG 角色，不重新设计岛壳，也不追加右侧数量格。V6 的岛壳形状与比例、中央双眼、蓝点、四任务卡片布局和汇入路径逐字保留。5.3 秒起左侧显示真实空闲圆角色；7.95 秒最后一张卡已完整进入岛壳，左侧切换真实思考三点，8.2 秒随原生审批面板出现而隐藏。四卡片的原时钟与运动未改。

中文全屏裁切由 CSS 优先级冲突引起：旧 `.stage-shell:fullscreen .stage-copy` 的 `left:7%` 胜过 V6 通用居中选择器，而后者的 `width:84%` 与 `translateX(-50%)` 仍生效，计算出的左边缘为视口 `-35%`。英文选择器较强所以没有同样问题。R7 给窗口、全屏、原生审阅壳和中英文统一居中规则，并使窄屏全屏字号规则拥有相同优先级。

18.1 秒起岛继续按原轨迹移向顶部刘海，同时中央增加站点六角色圆轨道。角色顺序保持站点的 egg、hexagon、play、idle、thinking、notify；角色本身的姿态、眨眼、思考脉冲、通知点和装饰弧线由真实引擎生成。归位文字从 46% 移至 81% 高度。中间段仍没有额外说明文案。

新增 `intro-bloub.ts` 直接导入 `aisland-website/src/vendor/bloub`，SVG painter 复用站点 `integrated-motion.ts` 的 SVG 层序和眼部 mask；没有按截图重新绘制角色。对应来源清单、当前文件 SHA256、上游提交 `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749` 和 MIT 许可放在 `assets/intro-bloub-source.json` / `assets/bloub-MIT.txt`。生成包是纯本地静态文件，不请求站点、不读取偏好、不增加独立 RAF 或音频时钟。

主流程真实浏览器报告：中英文全屏开场及左侧 SVG / 原岛壳正常；归位 21.1 秒静帧从窗口切入全屏时，父圆直径正确但六角色仍按旧窗口半径内聚。实际图片为主工作区 `output/verification/v0.1.1-intro-revision-7/browser-zh-fullscreen-home.jpg`。这是缓存只包含 sampled tick 的缺陷，不能由此前按理论几何重新组合的离线图片发现。
