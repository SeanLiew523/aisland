## 已固定的边界

- 正式 `dsh.bundle` + `dsh.client` 格式，Cordis `apply/inject/Config`；`ctx.on/ctx.effect` 负责卸载清理。
- `session/event(session,event)` 的 `turn/start` / `turn/end.reason.kind`；桥 wire 与 native 共同生命周期契约一致，snake_case、Unix ms，`deepseekHarness` 身份。
- 严格只投影 metadata。仅 `completed` 是成功；error/blocked/max-tokens、aborted、interrupted/forked 分别对应失败/中断，不使用 idle。
- 只发本次启动已观察 start 的对应 end；旧时间/seed seq/旧 turn/重复 seq/无 start 的 end 不制造通知，断连不回放。
- 源导航 socket 请求 `version/action/request_id/profile_id/session_id`，真实公共 client `uiWorkspace.openSession(id)`；回执仅 `dispatched/failed`。selection 为 private，不读取，不把 dispatch 当已选中与前台证据。
- browser RPC 使用源应用认证 channel，native endpoint 由 lifecycle `navigation_socket_path` 提供；默认与 bridge 同目录，隔离测试可覆盖。
- 审批/问答尚未可操作，不添加虚假按钮。
