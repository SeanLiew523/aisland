## 真实加载修复

真实 source 加载暴露两个 fakeCordis 测试没有覆盖的问题：linked 插件只能借用 bundled peerDependencies，所以 Schemastery 改为 peer；Cordis 的 `connection.rpc.handle` 持有 provider shadow，不能以 caller 的 webServer injection 注册。对实际导出的 `connection.register(ctx, channel, handler)` 显式传入 caller ctx，保留原认证 route；兼容 fallback 仍支持无 register 的 test/older API。没有改 source provider 注入或 bypass fence。
