## 可复现过程

辅助脚本：`scripts/verification/hermes-live.py`。以 Hermes 已有带 PyYAML 的 Python 运行，不增加依赖。

```sh
swift build --product OpenIslandHooks
~/.hermes/hermes-agent/venv/bin/python scripts/verification/hermes-live.py prepare \
  --source-home "$HOME/.hermes" \
  --hooks-binary "$PWD/.build/debug/OpenIslandHooks" \
  --source-commit 0ff4c748658ff5b92661fa2b453fcf8ed813414d \
  --app-source-commit 770df01fe77d8091d3808e3ed2ace16af2e8f6d5
# 使用 prepare 返回的全新临时 root；不要复用生产 profile。
~/.hermes/hermes-agent/venv/bin/python scripts/verification/hermes-live.py collect /tmp/aisland-hermes-<unique>
~/.hermes/hermes-agent/venv/bin/python scripts/verification/hermes-live.py run /tmp/aisland-hermes-<unique>
~/.hermes/hermes-agent/venv/bin/python scripts/verification/hermes-live.py summary /tmp/aisland-hermes-<unique>
```

`run` 必须使用真实 PTY，供人查看和确认 Hermes 自己的两条 consent 提示。它执行普通 `hermes chat -Q -q`，专用任务为 `Reply only AISLAND-HERMES-OK, don't call tools.`；`--ignore-rules` 跳过个人 instructions/memory，`--max-turns 1`、`--run-budget 90` 限制模型任务。没有 `hooks --test`、synthetic hook payload 或实际用户 session 读取。

collector 对整个 envelope/command/payload 检查字段，只接受 Hermes metadata contract、当前 profile 和当前 cwd；异常 envelope 不落盘。正常只保存元数据 NDJSON，并返回真实 `acknowledged`。需要停止 collector 时，在其自己 root 下创建空 `stop` 文件；collector 只删除自身新 socket。
