## 自动接入的实际运行环境补验

`b7755fe` 已把 `MiniMaxCodeSourceProbe` 纳入 App 的 Helpers 构建、复制、签名和结构校验。
原生安装器强制使用随包 helper，不在用户机器上调用 Swift 编译器；无外部 Node 时
使用已核对的官方 MiniMaxCode 3.1.0 内置运行环境，不启动 GUI 或任务。

主流程在最小 PATH 和固定 `ELECTRON_RUN_AS_NODE=1` 下，用实际官方执行文件运行
原样安装器，只操作临时 dataDir/supportDir：dry plan、安装/own-PID 预检、重复不改
receipt、owned 移除/再次缺失四项通过，3.088 秒；无 mcode 目录或外部 Node。
临时目录已删除。实际 MiniMax 现有进程唯一 active directory 的检测只读开放文件路径，
未读 SQLite、配置、凭证或会话正文。

整合后 source-only 构建：helper 1.14 秒，OpenIslandApp 14.17 秒，均通过；没有 App
打包/安装/启动。打包脚本语法和结构计划通过，新 helper 已列入 plan.helpers。
计划仍保留 R6 素材，因此既不是 R9 同步证明，也不是自动接入实际首启证明。

自动接入不是安装来源 Agent。它检测已安装来源并添加 AIsland 事件回调/插件；
未安装来源不写配置，用户显式停止自动配置的来源不会被启动流程重新启用。
来源尚未初始化 profile、正在运行且需退出、尚未激活/授权时，页面分别显示等待原因。
仅复制了插件不会显示为健康连接，需收到新真实 session-start 事件。
