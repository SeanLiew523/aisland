```sh

  --case setup-runtime \
  --socket /private/tmp/aisland-v011-acceptance/setup-runtime/bridge.sock \
  --build-number 39 --source-setup \
  --source-setup-agent hermes \

It exports the exact case socket and executes the admitted bundle's `Contents/Helpers/OpenIslandHooks`, preserving hook arguments. The existing source YAML/manifest are backed up under case support before migrating only AIsland's owned command. The original wrapper file remains untouched, as do user hooks, unrelated YAML and source-owned consent records. A new callback command still requires Hermes' normal consent. - MiniMaxCode Desktop: identify the active data directory from the exact running official source process/open-file metadata or an explicit manual confirmation. Only receipt/hash verified AIsland plugin files may move to the case connection. A relocated helper is copied to case support; the previous helper and receipt remain byte-identical. Old plugin/config/helper/receipt are backed up before migration. Foreign names, unknown files, changed hashes or partial ownership are refused. CLI remains disabled.
- DeepSeek Desktop: use the reviewed official source CLI/plugin path and its exact desktop profile. Case support hosts the managed package and backups; both task and navigation sockets point into the case. A running source with changed configuration waits for normal user exit; no automatic quit or task submission occurs. Current owned configuration does not need reinstalling.

`support/source-setup-receipts.jsonl` contains only fixed agent enum, fixed state enum and timestamp. States distinguish absent/installed, configured, consent/profile/source-exit/activation waiting, live event received, cancellation and error. They contain no names, paths, session IDs, body, credentials or error contents. UI installation status is not elevated to received/success. Explicit `uninstalled` intent survives restart and a later source installation.
