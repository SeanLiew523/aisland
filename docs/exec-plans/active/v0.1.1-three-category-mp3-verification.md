flow. Temporary copied routing/MCP settings were removed; credentials were never

MP3 is rejected while preserving the valid answer asset; restoring answer default
selects Bottle without changing completion/approval; reimport restores the answer
asset. Moving originals and restarting the same App retained three independent
selections and managed copies. The absence of a welcome window on this existing
domain is not fresh-install evidence.

automatic suppression. Polling every 20 ms observed stop at 5.094 s and full stop
