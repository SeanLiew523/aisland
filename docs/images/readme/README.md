# README visual assets

The English and Chinese READMEs share the approved AIsland website direction:
cobalt `#0808f2`, warm paper `#f4f4f0`, ink `#15116d`, and light Barlow Condensed
typography. The native demonstration is the focal point; the original C1 mark
and small native state animations accompany it.

## Artwork

`../readme-banner.svg` and `workflow.svg` are generated by
`scripts/generate-readme-art.py`. All lettering is converted to the unmodified
font's glyph outlines, so GitHub does not need to load fonts or execute HTML,
CSS or JavaScript inside an image. The flat-top 160 × 64 logo geometry and eyes
match `scripts/generate-aisland-appicon.swift`.

Barlow Condensed ExtraLight and Light come from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlowcondensed),
unmodified, under the included [SIL Open Font License](fonts/OFL-BarlowCondensed.txt).
The original font files are retained for repeatable artwork generation.

```sh
python3 -m pip install fonttools
python3 scripts/generate-readme-art.py
```

## Native recording

`native-demo-en.mp4` and the three `native-*-en.png` captures are byte-identical
to the approved website assets from website commit
`51812cf5dc08f8cb9ee8fcb22e7a83655e150537`. The recording uses the real native
views and existing English localization, with example sessions supplied through
the app's snapshot API. It does not record a live permission decision or a
session jump. Apple’s original Ventura wallpaper is a composited background.

`native-demo-zh.mp4` is exported from the original Chinese RGBA native recording
at app commit `111b21950f2319213432e4464c3f6ee6862ff95b`, using the repository's
existing `aisland-website/media/compose.py` and `demo-edit.json`. The export uses
3072 × 1984 with a 1024-pixel native panel, matching the English master's layout.
It starts from the original native frames, never a resized old GIF. The Chinese
README's stills reference the existing `native-sessions.png`,
`native-approval.png` and `native-complete.png` captures in the website assets.

`capture-provenance.json` preserves the original recording configuration,
native-view hashes, source commit and wallpaper attribution. `provenance.json`
contains this presentation's input hashes and export settings.
`capture-provenance-zh.json` records the Chinese capture and HD export.

Each 20-second GIF uses its language's recording at its original speed. It crops
the 3072 × 1984 desktop to 1440 × 900, starting at (816, 0), then scales that
region to 928 × 580 inside a 960 × 612 display frame. The wider, taller crop
preserves the full answer panel, including its input, submit button and session
footer. A 16-pixel opaque border works in both GitHub themes. There is no fade
or color overlay across the recording. It does not redraw, interpolate or
recolor the application interface. It loops at 15 fps; the website retains the
full-resolution 30 fps video and playback controls.

With FFmpeg installed:

```sh
sh scripts/export-readme-demo.sh en
sh scripts/export-readme-demo.sh zh
```

The four 64-pixel state previews reference the existing high-resolution native
WebP captures in `aisland-website/dist/assets/`, with no changes to their pixels
or timing. Their source metadata lives in `status-provenance.json` beside them.
The character adapts [bloub](https://github.com/jeremy-prt/bloub) under the
retained [MIT license](../../licenses/bloub-MIT.txt).

## README compatibility

Images use repository-relative paths, and the artwork has a fixed, opaque
background for consistent contrast in light and dark GitHub themes. Captions,
feature descriptions, download links and installation steps remain live text.
Long integration sections use GitHub's supported `details`/`summary` elements.
See [GitHub's README documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes).
