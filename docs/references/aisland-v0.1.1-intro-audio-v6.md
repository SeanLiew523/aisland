# AIsland v0.1.1 第六版引导音效

日期：2026-10-03。范围：独立审阅原型的原创调度模块；固定 22 秒。基线 `86f2865` 的开场保持原样。A 温润共鸣方向继续用于音色选择，实际舒适度与完整节奏仍待用户试听确认。

## 接线与取消

在 `review.js` 之前加载 `intro-audio.js`，由原来的 `scheduleIntro(base)` 调用：

```js
AIslandIntroAudio.schedule(base, timeline, {tone, air, swell});
```

`base` 必须使用现有共享 AudioContext 时钟的起点。模块没有新建 AudioContext、timer、播放源或取消入口；全部 30 次调用经过现有原语的 `track`，沿用 `stopSounds`。返回值为相对时间 cue 数组，仅用于审查；不返回新增节点，也不需要扩展原语。`cueSheet(timeline)` 可在无音频上下文时检查所有参数、起点和 `stopAt`。时钟基值与整段 cue 合法性会在创建首个音源前检查。

约定时间轴：`agents 3 / gather 5.3 / approval 8.2 / answer 10.7 / back 13.2 / completed 15.7 / dock 18.1 / settled 20.7 / duration 22`。本模块只负责整段引导，任务声音配置页的单独试听仍由宿主管理。

## 强度与重叠复核

按宿主原语包络每 1 ms 采样，对同时有效的 gain 作相加，得到不计相位抵消、滤波与压缩的保守振幅上界。该数值用于检查层间拥挤，不是输出波形、LUFS 或舒适度结论。

| 段落 | 最大 gain 和 | 同时存活音源数上限 |
| --- | ---: | ---: |
| 开场 | 0.5114 | 7 |
| Logo / 任务汇入 | 0.1866 | 6 |
| 审批 | 0.1050 | 1 |
| 回答 | 0.0660 | 3 |
| 任务继续 | 0.0348 | 2 |
| 完成 | 0.1400 | 2 |
| 回收 | 0.0646 | 3 |
| 贴合 | 0.0835 | 2 |

宿主 master 为 0.7；上述最大值发生在保留的开场。新增连续汇聚层的最大和小于开场，落位强度也低于审批和完成。存活源数包含渐弱与最后 0.02 秒余量，不等于各源同时到峰值；air 经低通后的实际输出与以上原始 gain 和不同。

## 验证与边界

`node --check` 通过。模拟三种 API 验证 30 次调用的类型、参数与共享 `base` 偏移；逐项比对基线开场 10 次调用完全一致；最后停止时间为 20.92 秒，全部音源在 22 秒内停止。非法时钟、缺失时间、超时落位或非 22 秒时长会在调度前拒绝，无部分音源创建。

尚未接线或试听本模块。需在主审阅页确认整段播放、静音/跳过/切页取消和视觉落点；只有用户试听才能判断温润感、triangle 质感、强弱舒适度与节奏是否认可。此处没有进入正式原生引导，也未修改任何用户导入音频。
